Votre liste d'attente est vide

Vous n'avez aucune candidature de place en attente. Si un cercle se libère pour une expérience complète, vous serez notifié.

États de Succès (Success States)

Bienvenue au Club

Votre compte membre 7Sens Premium est activé. Vous pouvez désormais vous connecter.

Règlement Validé

Votre paiement a été validé avec succès. Vos invitations vous attendent par e-mail.

Candidature Enregistrée

Vous avez rejoint la liste d'attente. Nous étudions votre profil pour assurer la parité.

Adresse E-mail validée

Votre adresse e-mail a été validée. L'accès aux inscriptions est maintenant débloqué.

Mobile activé

Votre numéro a été vérifié. Vos invitations vous seront envoyées par WhatsApp & SMS.

Mot de passe modifié

Votre nouveau mot de passe est configuré avec succès. Vous pouvez vous connecter.

4
États d'Erreur & Alertes (Error & Warning States)

Erreur d'éligibilité (Âge)

Désolé, votre âge ne correspond pas aux critères fixés pour cette expérience privée (28 - 45 ans). Nous appliquons ce filtre pour préserver l'affinité du cercle.

Échec du Règlement

La transaction de paiement a été déclinée par votre établissement bancaire (Solde insuffisant, code erroné ou carte expirée). Veuillez essayer un autre moyen de paiement.

Code OTP Saisi Incorrect

Le code de validation à 4 chiffres entré ne correspond pas à l'OTP envoyé. Veuillez revérifier vos messages ou cliquer sur renvoyer le code.

Code Promotionnel Invalide

Le code coupon ou code de parrainage inséré n'existe pas dans notre base ou a déjà expiré.
